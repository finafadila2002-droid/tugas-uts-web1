# tugas-uts-web1
Aplikasi toko buku online dengan nama BukuKita dibuat untuk mempermudah proses pengelolaan buku, mulai dari melihat daftar buku, mengatur stok, melakukan pemesanan, hingga mengetahui status pengiriman. Dalam pembuatan aplikasi ini menggunakan tiga bahasa pemrograman web, yaitu HTML, CSS, dan JavaScript. 
HTML digunakan untuk membentuk bagian-bagian halaman, seperti judul, formulir, tombol, menu, dan tabel.
CSS untuk mengatur tampilan agar aplikasi terlihat lebih menarik, mulai dari warna, ukuran tulisan, jarak antarbagian, hingga tata letak halaman.
JavaScript untuk menambahkan fungsi agar aplikasi dapat berinteraksi dengan pengguna. Contohnya seperti memeriksa data login, menambahkan data buku, dan memproses pemesanan.

Pertama terdapat halaman login. Pengguna harus memasukkan email dan password terlebih dahulu untuk masuk ke aplikasi.
Jika informasi yang dimasukkan benar, pengguna akan diarahkan ke halaman utama. Jika salah, sistem akan memberikan pemberitahuan bahwa login gagal.
Pada halaman ini juga terdapat fitur lupa password dan daftar yang ditampilkan melalui pop-up atau modal.

Setelah berhasil login, pengguna akan masuk ke halaman dashboard.
Halaman ini merupakan halaman utama yang berisi beberapa menu untuk mengakses fitur aplikasi. Terdapat menu katalog buku, stok, checkout, dan tracking.
Pada bagian dashboard juga terdapat sapaan yang menyesuaikan waktu pengguna membuka aplikasi.

<img width="960" height="600" alt="ss2" src="https://github.com/user-attachments/assets/54744fc1-a877-423e-9a14-861301421efd" />


Selanjutnya adalah halaman stok buku. Pada halaman ini, pengguna dapat melihat informasi buku yang tersedia.
Informasi yang ditampilkan meliputi kode buku, nama buku, penulis, harga, dan jumlah stok.
Pengguna juga dapat menambahkan data buku baru melalui formulir. Setelah tombol tambah ditekan, data akan ditampilkan pada tabel.

Berikutnya adalah halaman checkout. Halaman ini digunakan untuk memasukkan informasi pembeli dan data buku yang akan dipesan.
Pengguna dapat mengisi data pemesanan, menentukan jumlah buku, serta memasukkan informasi pembayaran.
Setelah data diisi, pengguna dapat menyimpan pesanan. Data yang berhasil diproses akan ditampilkan sesuai dengan fungsi yang tersedia pada aplikasi.

Halaman terakhir adalah tracking. Fitur ini digunakan untuk mengetahui status pengiriman pesanan.
Pengguna memasukkan nomor Delivery Order atau DO. Selanjutnya, sistem akan mencari data pesanan dan menampilkan informasi pengiriman jika nomor tersebut ditemukan.
Informasi yang ditampilkan meliputi nama pembeli, status pengiriman, nama kurir, tanggal pengiriman, jenis paket, dan total pembayaran.
